# SQL Query — Ontology Lake SQL 실행

회사 카탈로그를 대상으로 **SELECT 전용** Ontology Lake SQL을 실행합니다.

- **Endpoint**: `POST /open/v1/sql/query`
- **Tag**: `Open API`
- **인증**: API Key (`x-api-key`)

응답 래퍼/에러 포맷은 [공통 사항](/open-api/common) 문서를 참고하세요.

---

## Request

### Headers

| Header      | 타입   | 필수 | 설명                |
| ----------- | ------ | ---- | ------------------- |
| `x-api-key` | string | Y    | 발급된 API Key      |

### Body

```json
{
  "sql": "SELECT product_id, COUNT(*) AS cnt FROM warehouse.public.orders GROUP BY product_id LIMIT 10",
  "timeout": 300
}
```

| 필드      | 타입   | 필수 | 기본값 | 설명                              |
| --------- | ------ | ---- | ------ | --------------------------------- |
| `sql`     | string | Y    | -      | 실행할 Ontology Lake SQL 쿼리 (SELECT 전용) |
| `timeout` | number | N    | `300`  | 쿼리 타임아웃 (초)                |

---

## Response (`data`)

```json
{
  "columns": ["product_id", "cnt"],
  "rows": [
    { "product_id": "P001", "cnt": 1234 },
    { "product_id": "P002", "cnt": 987 }
  ],
  "rowCount": 2,
  "executionTimeMs": 412
}
```

| 필드              | 타입       | 설명                              |
| ----------------- | ---------- | --------------------------------- |
| `columns`         | string[]   | 컬럼 이름 목록 (응답 순서 보장)   |
| `rows`            | object[]   | 컬럼명 → 값 매핑의 행 목록        |
| `rowCount`        | number     | 결과 행 수                        |
| `executionTimeMs` | number     | 쿼리 실행 시간 (밀리초)           |

---

## Example

```bash
curl -X POST "https://[your-base-url]/open/v1/sql/query" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "sql": "SELECT product_id, COUNT(*) AS cnt FROM warehouse.public.orders GROUP BY product_id LIMIT 10",
    "timeout": 300
  }'
```

---

## 권장 사용 패턴

1. [`POST /open/v1/ontologies/query-translate`](/open-api/ontologies/query-translate)로 자연어를 Ontology Lake SQL로 변환
2. 응답의 `sql` 값을 `POST /open/v1/sql/query`의 `sql` 필드로 그대로 전달
3. 결과 `columns`, `rows`로 후처리/렌더링
