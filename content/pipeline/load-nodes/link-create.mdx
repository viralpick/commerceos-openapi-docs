# Ontology Link Create

두 온톨로지 오브젝트 간의 의미적 관계(링크)를 파이프라인 행 단위로 생성한다.

## 핸들 구조

본 노드는 두 개의 입력 지점(`From`, `To`)을 가진다. 각 입력 지점에 정확히 1개의 선행 노드가 연결되어야 한다.

## 설정

| 필드 | 필수 | 설명 |
|---|---|---|
| Link Type | Yes | 다음 중 하나를 선택한다: sameAs, subClassOf, partOf, hasPart, inverseOf, symmetric, relatedTo, disjointWith, SourceOf. |
| Predicate Term | No | 링크 라벨/용어 (예: "고객의 주문"). |
| Cardinality (From) | No | One and Only One, Many, Zero or One, Zero or Many, One or Many 중 선택. |
| Cardinality (To) | No | One and Only One, Many, Zero or One, Zero or Many, One or Many 중 선택. |
| Field Names (From Field) | No | 매핑할 From 측 필드명. |
| Field Names (To Field) | No | 매핑할 To 측 필드명. |

<Callout type="warning">
  From 입력 지점과 To 입력 지점에는 각각 정확히 1개의 선행 노드가 연결되어야 한다. 다른 구조에서는 검증 오류가 발생한다.
</Callout>
