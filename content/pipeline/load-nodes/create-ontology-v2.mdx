# Lake Ontology Create

대량 데이터를 효율적으로 일괄 업서트하여 온톨로지 오브젝트를 생성·갱신한다. 기존 두 단계 흐름(Upsert MongoDB → Create Ontology)을 한 단계로 통합한 신규 노드이며, **신규 파이프라인의 권장 노드**이다.

## 설정

| 필드 | 필수 | 설명 |
|---|---|---|
| Ontology Name | Yes | 생성할 온톨로지 이름. |
| Collection | Yes | 적재 대상 컬렉션. |
| Merge Keys | Yes | 동일 행 여부를 판단하는 기준 필드 (최소 1개). |
| Description | No | 온톨로지 설명. |
| Structure | No | 구조 정의. |
| Columns | No | 활용할 컬럼 화이트리스트. |

## 사용 전 확인

- 선행 노드와 연결되어 있어야 한다.
- Ontology Name, Collection, Merge Keys(최소 1개)는 모두 필수 입력값이다.

<Callout type="warning">
  본 노드는 기존 Upsert MongoDB + Create Ontology (v1) 두 단계 흐름을 대체한다. 신규 파이프라인은 본 노드를 사용한다.
</Callout>
