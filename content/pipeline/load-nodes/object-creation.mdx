# Object Creation

데이터프레임 행을 기반으로 온톨로지 오브젝트를 생성한다. 비정형 흐름(Parse Document → LLM Operator → Object Creation)의 적재 노드로 자주 사용된다.

## 설정

| 필드 | 필수 | 설명 |
|---|---|---|
| Object Name | Yes | 생성할 오브젝트 이름. |
| Primary Key | No | 주키로 사용할 필드. |
| Target DB Connection | No | 사용할 대상 DB 연결. |

## 사용 전 확인

- 다음 노드와 연결되어 있어야 한다.

## 관련 문서

- 사용자 측 오브젝트 관리는 [Object](/ontology-management/object) 참고.
