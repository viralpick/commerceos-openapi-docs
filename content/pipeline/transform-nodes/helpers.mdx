# Format Helpers

데이터 포맷을 다음 단계가 기대하는 형태로 변환하는 헬퍼 노드. 흐름상 Transform 단계에 위치한다.

## SQL → JSON

- DB 쿼리 결과를 행 단위 JSON으로 변환해 후속 노드(LLM Operator, JSON → Mongo 등)가 사용할 수 있게 한다.

| 필드 | 필수 | 설명 |
|---|---|---|
| Connection ID | Yes | DB 연결 ID를 입력한다. |
| SQL | Yes | 실행할 쿼리를 입력한다. |

## JSON → Mongo

- JSON 행을 MongoDB 적재 형식으로 변환한다. 보통 LLM Operator 뒤, Upsert MongoDB(legacy) 앞에 배치한다.
- 자동 변환 노드로 별도 설정 필드가 없다.
