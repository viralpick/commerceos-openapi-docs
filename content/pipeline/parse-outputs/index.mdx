# Parse Outputs

Parse Outputs는 `Parse Document` 노드를 포함한 파이프라인의 **비정형 파싱 결과를 검토하는 전용 화면**이다. 비동기로 실행되는 파싱 잡의 결과(markdown)와 원본 문서를 나란히 비교해 확인할 수 있다.

## 경로

`/pipeline/parse-outputs/[dagId]` (각 파이프라인의 DAG ID 기준).

## 언제 사용하는가

- `Parse Document` 비동기 잡의 결과를 확인할 때
- 실패한 파일을 찾아 재처리 정책을 결정할 때
- 후속 `LLM Operator`의 결과를 디버깅하기 전에 원본 파싱 markdown을 점검할 때
