# 결과 뷰어

Parse Outputs 화면은 3개 영역(헤더 / 좌측 잡 리스트 / 우측 결과 뷰어)으로 구성된다.

## 레이아웃

- **헤더 (상단)**: 파이프라인 displayName, 총 파싱 잡 수, 마지막 파싱 시간, Open Pipeline 버튼(클릭 시 해당 파이프라인 편집 화면으로 이동).
- **좌측 — 파싱 잡 목록**: 파일별 파싱 작업 목록을 표시한다. 무한 스크롤로 한 번에 최대 50개씩 로드된다. 파일명 검색을 지원하며 잡 카드에는 파일명·생성 시각·파일 크기·상태 배지가 표시된다.
- **우측 — 결과 뷰어**: 좌우 2단 구성으로 좌측은 원본 문서, 우측은 파싱된 markdown을 보여준다.

## 상태

| 상태 | 색상 | 의미 |
|---|---|---|
| Done | blue | 파싱 완료, 결과 확인 가능 |
| Failed | red | 실행 중 실패 |
| InProgress | green | 파싱 진행 중 |
| Pending | yellow | 실행 대기 |
| AwaitingUpload | yellow | 업로드 대기 |
| Cancelled | slate | 취소됨 |

## 지원 원본 포맷

- PDF, PPTX, DOCX, XLSX — 파일 종류에 따라 자동 식별되어 인라인 뷰어로 표시된다.
- 그 외 포맷은 인라인 미리보기가 지원되지 않을 수 있다.

## 결과 다운로드

- 상태가 Done인 잡에 한해 우측 헤더의 다운로드 버튼으로 결과 markdown을 `.md` 파일로 받을 수 있다.
- 파일명은 원본 파일명에서 확장자를 `.md`로 변환한 형태.

## 운영 팁

- Failed 발생 시 원본 파일 포맷·용량을 먼저 확인하고, Parse Document의 Enable OCR을 켜고 재실행.
- Open Pipeline 버튼으로 파이프라인 편집 화면으로 바로 이동할 수 있으므로 잡 결과를 보고 즉시 파이프라인을 조정할 수 있다.
