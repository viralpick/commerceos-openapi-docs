# 테스트 케이스 (Test Case)

온톨로지의 응답 정확도를 검증하기 위한 테스트 셋. 질문·예상 답변·LLM 답변·정답 여부·이유를 추적한다. 경로 `/ontology/test-case`.

## 구성 요소

- **질문 (Question)** — LLM에 던질 자연어 질의.
- **정답 (Expected Answer)** — 기대 응답.
- **LLM 답변 (LLM Answer)** — 실행 결과.
- **정답 여부 / 이유** — 비교 결과와 사유.

## 실행 방식

- **개별 실행** — 특정 케이스만 즉시 실행.
- **전체 실행** — 미진행 상태의 모든 케이스를 일괄 실행.
- **선택 실행** — 체크박스로 선택한 케이스만 실행.
- **테스트 취소** — 실행 중인 배치를 중단.

## 상태

| 상태 | 설명 |
|---|---|
| 미진행 (Unrun) | 아직 실행되지 않음 |
| 대기 (Pending) | 실행 대기 |
| 진행 중 (InProgress) | 실행 중 |
| 정답 (Passed) | LLM 답변이 정답과 일치 |
| 오답 (Failed) | 불일치 |
| 중단 (Stopped) | 실행 중단됨 |
| 실패 (Error) | 실행 중 오류 발생 |

## 운영 가이드

- 회귀 테스트 용도로 핵심 질문 셋을 유지하고, 온톨로지 변경 후 전체 실행으로 회귀 여부를 확인한다.
- 정답이 모호한 질문은 케이스로 등록하지 않는 것이 좋다 — 정답 여부 판정이 불안정.
