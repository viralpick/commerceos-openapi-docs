# MCP

외부 Agent가 내부 Ontology 도구를 사용할 수 있도록 **MCP(Model Context Protocol) 서버**를 발급·관리하는 기능입니다.

MCP 서버를 만들면 회사가 보유한 Ontology의 Object/Dictionary/Link를 외부 LLM 에이전트(Claude, Cursor 등 MCP 호환 클라이언트)에 도구(tool)로 안전하게 노출할 수 있습니다.

![MCP 서버 목록 화면](/mcp-list.png)

---

## 핵심 개념

| 항목       | 설명                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| **MCP 서버**   | Ontology 도구 묶음을 외부에 노출하는 단위. 이름·설명·노출 도구·응답 모델로 구성됩니다. |
| **노출 도구** | 외부 Agent가 호출 가능한 Ontology 리소스. Object 또는 Dictionary 단위로 선택합니다.   |
| **LINK 자동 추가** | 동일 MCP 서버에서 Object를 2개 이상 선택하면 두 Object를 잇는 LINK가 자동으로 도구에 포함됩니다. |
| **응답 모델** | 외부 MCP 클라이언트가 도구를 호출할 때 사용할 LLM 모델. 비워두면 시스템 기본값.       |
| **엔드포인트 URL** | 발급 시 생성되는 MCP 서버 주소. MCP 클라이언트의 서버 URL로 등록합니다.        |
| **토큰**       | 발급 시 1회만 노출되는 인증 토큰. 분실 시 서버를 재발급해야 합니다.                |

---

## 사용 흐름

1. **서버 추가** — MCP 페이지에서 우측 상단 `+ 서버 추가` 버튼을 눌러 새 MCP 서버를 만듭니다. → [서버 발급](/mcp/create-server)
2. **도구 선택** — 외부에 노출할 Object/Dictionary를 골라 묶습니다.
3. **발급** — 엔드포인트 URL과 토큰이 발급됩니다. 토큰은 다시 표시되지 않으므로 안전한 곳에 즉시 저장하세요.
4. **클라이언트 연결** — 발급된 URL과 토큰을 외부 MCP 클라이언트(Claude Desktop, Cursor 등)에 등록합니다. → [클라이언트 연결](/mcp/connect)
5. **활성/비활성 관리** — 서버 목록의 토글로 즉시 활성/비활성을 전환하거나, 더 이상 사용하지 않는 서버는 삭제합니다.

---

## 보안 권장사항

- 토큰은 **발급 직후 한 번만** 표시됩니다. 비밀번호 관리자, 사내 시크릿 보관소 등 안전한 위치에 저장하세요.
- 토큰이 유출되었거나 분실한 경우, 해당 서버를 비활성화한 뒤 새 서버를 발급해 교체하세요.
- 외부에 노출하지 않을 민감한 Object는 노출 도구에서 제외해 최소 권한 원칙을 유지하세요.
- 사용처별로 MCP 서버를 분리해 발급하면 토큰 회전과 권한 추적이 쉬워집니다.
