# 개인 계정으로 연결 (OAuth)

Claude Code에 주소 **하나**를 등록하고 AgentOS 계정으로 로그인하면, 로그인한 사람의 권한 안에서 온톨로지 챗·AI Builder·App Builder Magician 도구를 쓸 수 있습니다.

[서버 발급](/mcp/create-server) 방식과는 별개의 연결입니다.

| 구분 | 서버 발급 방식 (`/mcp/{server-id}`) | 개인 계정 방식 (`/mcp/me`) |
| --- | --- | --- |
| 인증 | 발급된 토큰 (Bearer) | AgentOS 계정 로그인 (OAuth) |
| 권한 범위 | 서버 발급 시 고른 Object/Dictionary | 로그인한 사람이 웹에서 쓸 수 있는 범위 그대로 |
| 회사 | 발급한 회사에 고정 | 호출마다 회사를 골라서 사용 |
| 도구 | 온톨로지 조회 도구 | 온톨로지 챗 · AI Builder · App Builder Magician |

두 방식은 토큰도 도구도 공유하지 않습니다.

<Callout type="warning">
  현재는 **Claude Code만 지원**합니다. Cursor 등 다른 MCP 클라이언트의 자동 등록(DCR)은 막혀 있습니다.
</Callout>

---

## 연결하기

주소는 하나이며, 회사마다 따로 등록하지 않습니다.

```
https://os.enhans.ai/agent-api/mcp/me
```

### 1. 서버 등록

프로젝트 루트의 `.mcp.json`에 아래 내용을 추가합니다.

```json
{
  "mcpServers": {
    "agentos": {
      "type": "http",
      "url": "https://os.enhans.ai/agent-api/mcp/me",
      "oauth": { "clientId": "agentos-mcp-cli", "callbackPort": 23449 }
    }
  }
}
```

또는 터미널에서 아래 명령으로 등록할 수 있습니다.

```bash
claude mcp add --transport http --client-id agentos-mcp-cli --callback-port 23449 \
  agentos https://os.enhans.ai/agent-api/mcp/me
```

### 2. 로그인

1. Claude Code에서 `/mcp`를 입력하고 **agentos → Authenticate**를 선택합니다.
2. 브라우저가 열리면 AgentOS 계정으로 로그인합니다.
3. **Connected to agentos**가 표시되면 완료입니다.

로그인은 처음 연결할 때와 토큰이 만료됐을 때만 다시 요구됩니다.

<Callout type="info">
  AgentOS 구성원으로 등록된 계정이어야 합니다. 등록되지 않은 계정은 403으로 거절됩니다.
</Callout>

### 3. 회사 고르기

연결 자체에는 회사가 없습니다. 먼저 "내가 쓸 수 있는 회사 알려줘"처럼 물어보면 클라이언트가 `list_my_companies`를 호출해 `company_id`와 회사 이름을 가져옵니다. 이후 질문부터는 클라이언트가 도구마다 그 `company_id`를 붙여 호출합니다.

쓸 수 있는 회사는 웹에서 고를 수 있는 회사와 같습니다. 역할이 배정된 회사가 열리고, 플랫폼 관리자는 모든 회사가 열립니다.

## 쓸 수 있는 도구

도구는 세 묶음이고, 묶음마다 **그 회사에서 기능이 켜져 있는지**와 **로그인한 사람의 권한**을 함께 봅니다. 권한 판정은 웹 챗과 같습니다.

| 묶음 | 열리는 조건 | 도구 |
| --- | --- | --- |
| 공통 | 항상 | `list_my_companies`: 쓸 수 있는 회사 목록 |
| 온톨로지 챗 | agent 실행 권한 | 웹 챗과 같은 온톨로지 조회, 지식 검색, Action 실행. 온톨로지 생성 기능이 켜진 회사는 생성 도구도 포함 |
| AI Builder | AI Builder 기능 + 편집 권한 | 웹 AI Builder 카탈로그 중 그 사람이 부를 수 있는 것. 조회와 변경안 제안까지만 하고, 반영은 AI Builder 화면에서 승인 |
| App Builder Magician | App Builder Magician 기능 | 대시보드 조회·생성·편집 |

알아 둘 점:

- **도구 목록과 실제 호출은 다릅니다.** 클라이언트의 도구 목록에는 어느 회사에서든 열릴 수 있는 도구가 모두 보입니다. 목록에 있어도 고른 회사에서 기능이 꺼져 있거나 권한이 없으면 호출 때 거절됩니다.
- **Action 실행에는 되묻는 단계가 없습니다.** 웹 챗의 확인 화면 대신 Claude Code의 도구 승인이 그 역할을 합니다. 실행 기록에는 로그인한 사람이 실행자로 남습니다.
- **회사를 바꿀 때는 확인을 거치도록 안내합니다.** 다른 회사로 옮겨 쓰기 전에 사용자 확인을 받으라는 규칙은 클라이언트 지시문에만 있고, 서버가 막지는 않습니다. 작업 중 회사가 바뀌었는지 응답에서 확인하세요.
- `company_id`는 문자열로 주고받습니다.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| 로그인 후 브라우저에 404 또는 연결 오류가 표시됨 | 23449 포트를 다른 프로그램이 쓰고 있을 수 있습니다. `lsof -nP -iTCP:23449`로 확인한 뒤 해당 프로그램을 종료하세요. 이미 열린 오류 페이지라면 주소창의 URL 전체를 복사해 Claude Code 인증 화면에 붙여 넣으면 로그인이 완료됩니다. |
| `needs authentication`이 계속 표시됨 | `/mcp` → agentos → **Clear authentication** → **Authenticate** 순서로 다시 로그인하세요. |
| `.mcp.json`을 수정했는데 반영되지 않음 | Claude Code를 재시작하세요. |
| 403 "AgentOS 사용자로 등록되지 않은 계정입니다" | 로그인한 계정이 AgentOS 구성원이 아닙니다. 관리자에게 구성원 등록을 요청하세요. |
| "회사 N 에 권한이 없습니다" | 그 회사에 역할이 배정되지 않았습니다. 해당 회사 관리자에게 역할 배정을 요청하세요. |
| "회사 N 에서는 'X' 을 쓸 수 없습니다" | 그 회사에서 해당 기능이 꺼져 있거나 권한이 없습니다. 위 도구 표의 조건을 확인하고 관리자에게 문의하세요. |
| 로그인 화면이 열리지 않음 / 503 | 서버 쪽 인증 설정 문제입니다. 관리자에게 문의하세요. |
