Notebook Transform

Jupyter 스타일 셀 편집기에서 Python으로 데이터프레임을 가공한다. Custom Node와 달리 셀 단위 + 파라미터 바인딩 + 코드 자동완성을 지원하므로, 코드 작성과 검증이 더 용이하다.

사용 시점

표준 Transform 노드로 해결되지 않는 가공이 필요하며 Python으로 구현 가능한 경우에 사용한다.

주요 설정 항목

필드필수설명
CellsYesPython 코드 셀과 설명용 마크다운 셀을 자유롭게 추가한다.
ParametersNo이름·타입(문자열·숫자·불리언·없음)·값을 정의하면 코드 셀에서 동일한 이름의 변수로 사용할 수 있다.
Timeout (seconds)No실행 타임아웃. 1초 ~ 30분 범위로 설정한다.

권장 사용 순서

표준 Transform 노드 → Notebook Transform → Custom Node → Custom 순으로 선택을 검토한다.
